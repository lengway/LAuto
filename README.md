# LAUTO

# Сервис для рецензий и поиска деталей для каждой машины с ИИ-мануальщиком для каждой машины.

---

## Суть сайта

Сайт будет работать как каталог машин: марки, модели, комплектации, детали, фото. На каждую марку, модель, комплектацию, деталь, будут находиться лучшие предложения на рынке по стране пользователя.

---

## Интерфейс

Сайт будет обладать приятным интерфейсом сделанным на React + shadcn/ui библиотеке.

---

## ИИ

Сервис будет обладать ИИ-ассистентом, который поможет как и подобрать машину, так и сможет помочь с заменой/ремонтом. ***2 модели:*** одна будет помогать с подборкой машины, комплектации, вторая будет помогать с ремонтом/заменой деталей, запчастей. Первая будет обучена на рецензиях к машинам из сети, вторая будет обучена на DIY инструкциях из сети и официальных манулах производителей, так мы обойдем запрет на использование мануалов без подписок от производителей авто.

---

## Рецензии

Каждый зарегестрированный пользователь сможет оставить свою личную рецензию или опыт пользования автомобилем.
